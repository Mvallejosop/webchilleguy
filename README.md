# Chill e Guy — V2.13

Navegación: Home, Services, Journal y Contact. Se elimina la página Studio.
Se conservan las imágenes compartidas, los artículos y el lockfile corregido
de la carpeta local del usuario.

## Abrir

Abre esta carpeta en VS Code y ejecuta:

```bash
npm install
npm run dev
```

Para compilar: `npm run build`. El sitio genera siete páginas estáticas.
El formulario de Contact abre un borrador en la aplicación de correo.
Los artículos se editan en `src/content/journal/`.
